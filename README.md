## Cara Menjalankan
1. `npm install`
2. `npx expo start`
3. Scan QR dengan Expo Go (Android/iOS)

## Fitur
- Profil & identitas mahasiswa (Level 1-2)
- Layout responsif + theme light/dark (Level 3, 7)
- Form kontak dengan validasi & feedback (Level 4, 10)
- Data terpisah di folder `data/*.json` (Level 5-6)
- Skills (FlatList), Portfolio (search), Experience Timeline (Level 7)
- My Score + Learning Progress (Level 8)
- Navigasi bottom tab 6 halaman (Level 9)
- Empty/Error/Loading states, dokumentasi, pengujian (Level 10)

## Struktur Data
- `data/profile.json`
- `data/skills.json`
- `data/portfolio.json`
- `data/experience.json`
- `data/academicScore.json`
